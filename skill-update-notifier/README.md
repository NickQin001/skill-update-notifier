# Skill 更新检查 · 0.1.1 手动试用版

用户主动检查已安装 Skill，与确认的公开 GitHub 或 SkillHub 来源比较，查看上游变化和本地差异，再决定是否值得更新。

**当前提供：**单个 Skill 只读检查、可核验历史基线比较、文本及二进制文件比较、Markdown/JSON 报告和人工更新建议。AI 可逐项调用并汇总多个 Skill。

**新增 SkillHub 来源：**通过公开 API 核验版本记录、固定版本文件 SHA256、发布说明及可验证的公开文本差异；不要求下载或执行来源代码。发布说明是作者提供的信息，不是效果验证。

**当前不提供：**调用后自动提醒、使用频率采集、五次拒绝计数、持久偏好、代为更新/合并/回滚。接入 SkillHub 来源检查不等于本工具已获平台收录或审核。

## 安装与使用

把整个 `skill-update-notifier` 文件夹放入你的 AI 工具支持的 Skill 目录，保留 scripts 和 references。各宿主是否识别、是否允许执行 Python/Git，按实际环境核验；本版不宣称所有 AI 工具兼容。已有同名目录时先备份并审阅差异，勿直接覆盖。

随后向 AI 提出：

> 使用 skill-update-notifier，检查我指定的 Skill 有没有值得更新的内容。先核对安装目录和原来源，说明本地差异，不能直接更新。

也可独立运行 CLI，完整参数与边界见 [usage.md](references/usage.md)。需要 Python 3.10+；GitHub 来源还需要 Git。没有第三方 Python 依赖，安装时保留 scripts 中两个脚本。

本版只读取本地文件，不上传本地 Skill 内容、不执行更新。第一次缺少历史基线时，即使文件不同也只报告差异，不宣称发现新版。输出的目标提交可保留为未来检查的观察基线。

本地测试不能证明长期用户收益。请反馈：这次摘要是否帮助你决定更新/保留，以及决定的主要理由；反馈前删除本机路径和敏感内容。

SkillHub 按原始字节哈希比较，换行/BOM 差异也会计入；GitHub 文本比较忽略这些差异。SkillHub 额外安装元数据（例如下载包附带的 `_meta.json`）仍列为本地差异，不据此认定上游更新，不删除。
